# Contributing

Thanks for improving Local App Control Center.

## Local Development

- Keep the repository focused on source, scripts, docs, and assets.
- Do not commit generated executables, `controlcenter.ini`, logs, temporary files, machine-specific paths, or secrets.
- Build on Windows with `BUILD_EXE.bat` or `build_windows_exe.ps1`.
- Prefer small, focused changes with clear commit messages.

## Pull Requests

Before opening a pull request:

- Confirm the app builds successfully on Windows.
- Confirm the UI can start and stop configured local services.
- Update `README.md`, `CHANGELOG.md`, or `RELEASE_NOTES.md` when behavior changes.
